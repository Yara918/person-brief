# person-brief · 详细规则（按需加载）

## A. 锁定降级链

```
① 人名 + 公司 + 职位 → 查公开信息（履历/言论/社媒）
   ├─ 查到，且公开信息对应他给的职位 → 就是这个人 → 研究他
   ├─ 查不到该人 → 降级 ↓
② 该公司法定代表人 → ③ 董事长 → ④ CEO/总经理 → ⑤ C-level 高管 → ⑥ 部门负责人
⑦ 全链查不到 → 如实写「未检索到可研究的人物公开信息」，报告如实薄
```

**降级执行规则（硬性）**：
- **严格按序，禁止跳级**：未试法定代表人/董事长前不得直达高管。
- **同级优先相关**：指定采购类职位查无时，高管层优先选分管采购/供应链者；其信息太少再按原顺序继续。
- **降级必须明示**：聊天中明确说「指定人查无，已降级研究该公司<层级> <姓名/职务>」，报告定位层级标注「② 法定代表人（指定人查无，降级）」式说明。
- **禁止换人**：相似人名 ≠ 降级目标，不得擅自替换研究对象；先询问用户确认。

- 人物身份确认：靠公开言论/资料与用户给的信息（公司+职位）能否对应来判断。
- **不调查不背调**：只研究公开职务身份与公开言论，不深挖隐私（住址/电话/家庭/非公开账号）、不查工商涉诉记录、不突破登录墙。

## B. 分层查询规则（写进检索清单，用户可见）

**社媒（人物号）**：
- 必查 4：微博 / 领英 / X / 抖音
- 按行业查：小红书 / B站 / 知乎 / 脉脉（看人物行业与公开度）
- 每平台独立查询，命中写【账号名 + 粉丝数 + 美观链接按钮】，查不到写「未检索到 + 检索记录」

**履历与言论**：
- 履历：公开资料/官网团队页/新闻提及（带来源）
- 言论：有公开采访/演讲/表态 → 双声道；没有 → 如实写「未检索到公开言论」

## C. 内容字段字数上限

| 字段 | 上限 |
|---|---|
| 身份一句话 | ≤ 40 字 |
| 背景轨迹（3-4 节点） | 各 ≤ 40 字，带来源 |
| 双声道（他说 vs 外界） | 各 ≤ 50 字，带来源 |
| Gap 解读 | ≤ 60 字 |
| 谈资（3 个） | 各 ≤ 60 字 |
| 避雷（1 个） | ≤ 60 字 |

## D. 社媒链接呈现（美观，不裸链）

```
命中账号 → 美观平台卡片：
  [平台图标] 账号名（粉丝 xxx） [进入主页→按钮链接]
查不到 → 「未检索到（环境限制可在 App 内搜索账号名）」+ 检索记录
禁止：裸 URL、纯文字「来源：xxx」
```

**关键规则**：
- **链接必须是账号主页**：社媒区按钮只允许指向该平台的账号主页（如 weibo.com/u/xxx、douyin.com/user/xxx、linkedin.com/in/xxx）。
- **报道 ≠ 账号**：只查到新闻报道提及账号存在、但主页未检索到时，写「未检索到账号主页，仅见报道提及」并把报道链接放检索记录，**禁止把报道链接当社媒主页按钮**。

## D2. 渲染约定（report-template.html 填充）

- 来源一律填成按钮链接：`<a class="srclink" href="真实URL">来源</a>`，禁止裸 URL；**按钮文字必须描述来源**（百科/公司官网/新闻/财报等），禁止统一写「来源」「来源1」「来源2」。
- 社媒区 `{{sm_rows}}` 按表格行填：`<tr><td>平台名</td><td><span class="uname">账号名</span><span class="fans">粉丝数</span></td><td><a class="btn" href="真实URL">进入主页</a></td></tr>`；未检索到 → 同结构，账号格写「未检索到」，操作格留空。
- **社媒按钮必须是账号主页链接**（weibo.com/u/xxx、douyin.com/user/xxx、linkedin.com/in/xxx 等），**且必须来自检索结果原文**，禁止按 ID 格式推测编造；只查到报道提及 → 写「未检索到账号主页，仅见报道提及」，报道链接放检索记录，**禁止把报道链接当社媒主页按钮**。
- 背景轨迹 `{{timeline_items}}` 填：`<div class="tl-item"><span class="y">年份</span><span class="d">节点描述</span></div>`，3-4 个节点，**每个节点必带来源**。
- 双声道 `{{self_items}}` / `{{media_items}}` 填：`<li>内容 <a class="srclink" href="真实URL">来源</a></li>`，各 1-2 条，**每条必带来源**；无公开言论 → 写「未检索到公开言论」。
- **内容点来源完整性**：破冰抓手/身份/轨迹/双声道/谈资/避雷/Gap 每一条都必须带可点来源；缺来源 → 补来源或写「未检索到出处」，禁止裸内容。
- 内容字段里的空白占位：查不到写「未检索到」，来源按钮给真实检索记录链接。

## E. 免责声明

- 社媒区：`社交账号基于公开检索结果整理，受各平台可见性、登录墙与检索覆盖限制，账号无法保证收录完全，仅供会前参考；未检索到 ≠ 不存在。`
- 人物信息区：`本简报仅基于公开职务信息与公开言论整理，不涉及个人隐私调查，仅供会前参考；未检索到 ≠ 该人物无相关信息。`

## F. 检索记录（透明可复核）

```
附录写「已检索平台 / 未检索到平台 / 检索记录」：
  已检索：微博✓ 领英✓ X✓ 抖音✓ 履历✓ 言论✓
  未检索到：小红书（该行业少用）· B站（未发现）· …
  检索记录（每条 = 平台×关键词×结果）：
    微博：搜"人名" → 无公开账号
    领英：搜"人名 公司" → 命中主页（链接）
    履历：搜"人名 履历" → 公开资料页（链接）
→ 用户打开复核：平台真查过、分类理由可解释
```

- **来源不重复**：同一 URL 全报告最多出现 2 次；**降级场景例外**：同一官网 URL 最多 3 次，且必须至少配 1 个非官网来源，禁止全篇只用一个来源；超出即换替代来源或如实标注。
- **登录墙/403 标注**：企查查/启信宝/天眼查等工商平台及反爬站点引用时，链接文字标注「需登录」或「访问受限」，并优先配一个免登录来源（官网/新闻/百科）；渲染前逐条自检，拿不准的链接不引用。
