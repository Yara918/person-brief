# examples · 示例

本目录存放虚构示例（公司 / 人名一律用代称，不含任何真实客户信息）。

## 如何查看示例效果

1. 打开本技能的 `report-template.html`，按模板占位符填入虚构数据，即可预览报告版式。
2. 或在任意支持 Agent Skill 的平台安装本技能后，用虚构人物跑一次完整流程。

## 示例数据（虚构，仅演示版式与字段）

| 字段 | 示例值 |
|---|---|
| 人名 | 示例人物 |
| 公司名 | 示例科技有限公司 |
| 职位 | 采购总监 |
| 定位层级 | ① 人名+公司+职位 直接命中 |
| 破冰抓手 | 他最近在行业峰会谈过供应链数字化，可从此切入 |

> 注意：示例中的链接均为虚构占位（如 example.com），仅用于展示版式，不代表真实来源。
